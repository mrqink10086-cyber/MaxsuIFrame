# Skyrim 1.6.1170 ABI 核验

## 范围与输入

- 目标：Steam Skyrim SE / AE `1.6.1170.0`，SKSE64 `2.2.6`。
- 依赖：`E:/source/repos/CommonLibSSE-NG-ng`，本地版本 `15.7.3`。
- 二进制：`E:/source/repos/valhallaCombat/build/abi/SkyrimSE-1.6.1170.exe.unpacked.exe`。
- 地址库：`E:/source/repos/CommonLibSSE-NG-ng/tests/REL/versionlib-1-6-1170-0.bin`。
- EXE SHA-256：`80c1ea737d33c6bfac09b101b8d77ab0f9f6630128c3ed052f9d945bed54e7e4`。
- 地址库 SHA-256：`c4093c569a3c83b26587f4b9ea4c55de9ae6e73b84a2af9fb3fbd30e2fe0d452`。

所有地址均为 RVA。实际装载地址为模块基址加 RVA，不应把这里的 RVA 当作固定进程地址。

## IsGhost 调用点

插件修改的是三处非虚成员函数调用指令，未写入虚表。NG 的 `RE::Actor::IsGhost() const` 使用 SE / AE ID `36286 / 37275`；1170 下 AE ID `37275` 解析为 RVA `0x662C90`。

| AE Address Library ID | 函数内偏移 | 指令 RVA | 原始字节 | 解码目标 RVA |
| --- | --- | --- | --- | --- |
| 38627 | `+0x47` | `0x6BA8B7` | `E8 D4 83 FA FF` | `0x662C90` |
| 37725 | `+0x22` | `0x68D902` | `E8 89 53 FD FF` | `0x662C90` |
| 40504 | `+0x14` | `0x737954` | `E8 37 B3 F2 FF` | `0x662C90` |

结论：原代码 AE 的三处偏移在 1170 下均正确，无需修改数值。现场指令前设置 `RCX` 为 Actor 指针，调用后检查 `AL`，与 `bool(const RE::Actor*)` 的 x64 ABI 一致。

新入口在任何地址库查询前检查游戏运行时和最低 SKSE 版本。安装 Hook 前先核验全部调用点，再写入三个调用；原函数统一保存为已验证的 ID `37275`，避免反复覆盖原函数指针。

## 虚函数与结构

`hkReferencedObject::GetClassType()` 为零起算槽位 `0x01`，虚表字节偏移 `+0x08`。`hkbNode` 经 `hkbBindable` 继承该槽位，不能把它当成槽位 0。

`IAnimationGraphManagerHolder::GetAnimationGraphManager()` 与 `GetGraphVariableBool()` 是普通包装函数。前者分派至 `GetAnimationGraphManagerImpl` 槽位 `0x02`（`+0x10`）；后者分派至 bool 版本 `GetGraphVariableImpl3` 槽位 `0x12`（`+0x90`）。这些槽位属于 Actor 的 `IAnimationGraphManagerHolder` 子对象虚表，并非 Actor 主虚表。详细的二进制目标和反汇编证据由 `abi-1170.json` 记录。

插件访问的 NG 字段布局已按本地头文件核对：

| 类型 / 字段 | 字节偏移 | 核对依据 |
| --- | --- | --- |
| `BSAnimationGraphManager::graphs` | `0x40` | NG 头文件 |
| `BShkbAnimationGraph::behaviorGraph` | `0x208` | NG 头文件 |
| `hkbBehaviorGraph::activeNodes` | `0x98` | NG 头文件 |
| `hkbNodeInfo::nodeClone` | `0x58` | NG 头文件 |
| `hkbClipGenerator::binding` | `0xA0` | NG 头文件 |
| `hkbClipGenerator::localTime` | `0xF0` | NG 头文件 |

字段表为头文件布局核对，不等同于逐字段二进制验证。1170 使用 1.6.629 之后的布局；通过 NG 的 `GetRuntimeData().updateLock` 取得 `+0xA0` 的管理器更新锁，持锁检查图数组再读取 `graphs[0]`。锁的反汇编依据与保证范围见 [性能与安全审核](PERFORMANCE-SAFETY.md)。

`hkbClipGenerator::GetClassType` 的虚表项和跳转目标已从 PE 核对；返回的类描述符位于该 PE 的非文件映射数据区域，因此报告不声称已从文件验证其类名字符串。

## 复核

```powershell
python -m pip install capstone
python tools/verify_1170.py `
  E:/source/repos/valhallaCombat/build/abi/SkyrimSE-1.6.1170.exe.unpacked.exe `
  E:/source/repos/CommonLibSSE-NG-ng/tests/REL/versionlib-1-6-1170-0.bin `
  --output docs/abi-1170.json
```

脚本会独立解码地址库与 PE，再核对指令和虚表，任一检查失败则返回非零退出码。二进制核验和编译通过不能替代游戏实测；仍需在 1170 中验证翻滚无敌帧、普通受击、原本 Ghost 状态以及与其他战斗模组的组合行为。
